# Михаил Красильников

Занимаюсь аналитикой, архитектурой и разработкой программного обеспечения. Создаю инструменты для организации разработки с ИИ, пишу об инженерных подходах и документации.

## Разработка с ИИ

Мои текущие проекты:

- [ai-dev-team](https://github.com/mekras/ai-dev-team) — подключаемая команда агентов для разработки ПО: роли, навыки и правила работы от анализа задачи до проверки результата.
- [ai-agent-supervisor](https://github.com/mekras/ai-agent-supervisor) — навыки для создания и улучшения инструкций и навыков агентов, настройки их работы и разбора ошибок.
- [project-knowledge-corpus](https://github.com/mekras/project-knowledge-corpus) — создание, сопровождение и применение корпуса знаний проекта для работы с ИИ.
- [ai-russian-language](https://github.com/mekras/ai-russian-language) — навыки использования русского языка для агентов, включая технические тексты и документацию.

## Книги и документация

- [«Эффективная разработка ПО»](https://mekras.github.io/effective-development/) — книга об инженерных подходах к разработке программного обеспечения. Книга в работе. [Исходники](https://github.com/mekras/effective-development).
- [«Как писать документацию»](https://github.com/mekras/hwd) — материалы о документации, связанной с программным обеспечением и его разработкой: руководства, справочники и шаблоны.

## Библиотеки и инструменты

- [php-speller](https://github.com/mekras/php-speller) — библиотека PHP для проверки правописания через Aspell, Hunspell и Ispell.
- [sphinx-doc](https://github.com/mekras/sphinx-doc) — среда Sphinx в Docker и шаблон проекта для сборки документации в HTML и PDF.
- [ptgrep](https://github.com/mekras/ptgrep) — инструмент для проверки значений в выводе консольных команд. Например, для контроля порогов качества кода в CI.
